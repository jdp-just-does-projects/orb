# fixtures

Small CC0 / self-generated media files used by tests and benchmarks: one file per format
(JPEG, PNG, WebP, HEIC, AVIF, JXL, TIFF, GIF, CR2, CR3, NEF, ARW, DNG, RAF, MP4, MOV, MKV, WebM,
AVI, MTS) plus `expected.toml` listing the metadata each test asserts on.

`fixtures/corpus/` (git-ignored) holds generated bulk corpora for benchmarks.
